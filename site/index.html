切换项目，
整套工作环境一起切换

对 AI 来说，一个会话就是一个项目；人却还要在论文、Overleaf、终端和日程之间来回翻找。
Gleeok 以项目为单位，把它们摆进同一个分栏工作台。

下载 Gleeok 在 GitHub 上查看源码

macOS · Windows · Linux  ·  数据默认保存在本机

01

每个项目，一套分栏

AI 对话、主工作区、辅助资料，各占一栏，每栏有自己的标签页。项目记得每一栏开着什么。

02

点一下，全部切换

在侧边栏点一个项目（或 ⌘[ ⌘]），所有栏、所有窗口一起跟着换。旧项目不会被关掉，回来时原样还在。

03

多屏是一等公民

任意一栏都能拆成独立窗口放到另一块屏上，并且同样跟着项目切换；重启后回到原来的位置。

文献阅读

内置 PDF 阅读器
高亮批注都进文献库

基于 Zotero 的阅读器。划选文字、选一种颜色，高亮和批注同步进文献库，在侧栏点一下就跳回原文。

  • 多色高亮、批注、页面跳转
  • 划词翻译（DeepL 或兼容 OpenAI 的接口）
  • 阅读状态、笔记和附件都挂在条目上
日程

任务、时间块、番茄钟
按项目分组

在日历上拖出一段时间就是一个新任务；点开正在进行的时间块开始番茄钟，侧边栏一直显示倒计时。

  • 日 / 3 日 / 周 / 月视图，拖动创建和移动
  • 任务按项目分组，新标签页上也能看到今天的安排
  • 手机页面随手记，和桌面端同步
文献库

像 Zotero 一样管论文
一键引用到 Overleaf

分类、标签、阅读状态。条目信息可以从 DBLP 补全，复制 BibTeX 或 \cite{} 直接贴进论文。

  • 拖入 PDF 自动建条目
  • DBLP 补全作者、会议、DOI
  • 可以在任意一栏里打开，也可以全屏
Paseo

Paseo 的项目一键导入
agent 对话就在 AI 区

连上你的 Paseo daemon，勾选项目导入。每个项目自动带上最近用过的 workspace 和它的终端，打开项目，agent 的对话就在左边那一栏。

  • 多台机器的 daemon 都能接入，经 Paseo 的加密中转，不用开端口
  • 链接自动跟着最近的 workspace 走
  • 检测到 code-server 时，一键打开项目的代码

还有这些

⌁

Agent 接入

通过 REST 或 MCP，让 Claude Code、Codex 帮你排日程、存论文。每个连接单独的令牌，随时吊销。

›_

内置终端

本机或 SSH 的终端开在任意一栏里，项目休眠时也不会断；支持 Nerd Font 图标的提示符。

⇄

本地优先，可选同步

默认本地存储；也可以部署自己的同步服务器，标签页在多台设备之间接力。

⚿

密码库

接入 Bitwarden 兼容的密码库（包括自建的 Vaultwarden），快捷键填充。

☾

省内存的休眠

不活跃的项目在每天的分界点自动休眠，打开时才加载。

↻

自动更新

正式版跟随 GitHub Releases；测试版可以热更新，不用重新安装。
