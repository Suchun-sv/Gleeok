# Gleeok 文献库 — Spec v3

第一期：管理界面 + PDF 阅读器。状态：M1–M3 已完成（2026-10-23），M4（设置页、缓存上限、性能打磨）待做。

## 1. 目标与范围

一个仿照 Zotero 的文献库，作为 Gleeok 的一级功能。数据在自己的服务器上（Gleeok 同步服务器），
多台电脑共享；本地模式下在本机。

**第一期做**

- 管理界面：分类、条目、标签、笔记、附件、回收站
- PDF 阅读器：阅读、高亮、批注，批注和阅读位置跨设备同步
- 最基本的添加方式：手动新建条目、拖入或选择 PDF 文件（为了让库里先有东西，不是导入功能）

**第一期不做**

- 网页收藏、按 DOI / arXiv / ISBN 抓元数据（Zotero translation-server）
- 从 Zotero 迁移
- 与 Gleeok 项目关联（文献库和项目各自独立）
- agent / MCP 接口、`refs.bib`、引用格式、Word 插件

## 2. 已定的决定

| | 决定 |
|---|---|
| D1 阅读器 | 嵌入 Zotero 的阅读器 [`zotero/reader`](https://github.com/zotero/reader)（网页版构建，`window.createReader(options)`）。它是 AGPL-3.0，所以阅读器并入时 Gleeok 从 Apache-2.0 改为 AGPL-3.0 |
| D2 项目关联 | 不做 |
| D3 文献库在栏里打开 | 第一期就做：既能占满主窗口右侧区域，也能作为标签页放进任意一栏 |
| D4 默认值 | 快捷键 Prefix+P；PDF 默认在第 3 栏打开（没有第 3 栏就用最后一栏），可在设置里改 |

已验证（2026-10-23，mini-cachyos）：`zotero/reader` 的网页版构建约 1 分钟，产物 12 MB；在 Gleeok
所用的 castLabs Electron 44 里能直接加载示例 PDF，工具栏、批注工具、侧栏、深色主题、阅读位置回调都正常。
界面文字来自 Zotero 主仓库的翻译文件，可以用简体中文。

## 3. 入口

| 入口 | 形式 |
|---|---|
| 侧边栏 | 项目列表下方、底部状态栏（内存占用那一行）正上方固定一行「📚 文献库」，右侧显示条目数。点击打开文献库（占满右侧区域），再点回到栏视图；打开时高亮 |
| 快捷键 | Prefix+P 打开 / 关闭文献库 |
| 新标签页 | 「常用」上方一块「文献库」：「在这一栏打开文献库」，以及最近读过的 6 篇（点击在这一栏打开 PDF） |
| 命令面板 | 「打开文献库」「在焦点栏打开文献库」；按标题、作者搜索条目，回车打开 PDF |

## 4. 管理界面（Zotero 式三列）

同一套界面有两种放法：

- **全屏**：占满主窗口右侧原来放栏的区域（同「设置」页）。顶部有「在栏中打开」按钮。
- **栏内标签页**：`gleeok://library`，可以在任意一栏打开、拖到别的栏、拆到别的窗口，和终端标签页一样。
  栏窄时自动收起：宽度不够三列时，分类列变成可展开的抽屉，详情列变成从右侧滑出的面板。

```
┌ 分类 ──────────┬ 条目列表 ───────────────────────────────┬ 详情 ─────────────┐
│ 📚 我的文献库   │ 🔍 搜索标题/作者/年份/标签   [+ 新建 ▾]   │ [信息] [笔记] [附件] │
│ 🕘 最近添加     │ 标题              作者      年份  期刊  📎│ 条目类型 ▾          │
│ 📖 最近阅读     │ ▸ Attention Is…   Vaswani…  2017  NeurIPS│ 标题 ____________   │
│ 📄 未分类       │   LoRA: Low-Rank… Hu et al. 2021  ICLR  │ 作者 + − ↑↓        │
│ 🗑 回收站       │   …                                     │ 日期/期刊/卷/页/DOI │
│ ─────────      │                                         │ URL / 摘要          │
│ ▾ 论文 A        │                                         │ 标签 [+]            │
│   ▸ 相关工作    │                                         │ 阅读状态 ▾          │
│ ─────────      │                                         │                     │
│ 标签：#LLM #KV… │                                         │                     │
└────────────────┴─────────────────────────────────────────┴─────────────────────┘
```

**分类列**：内置「我的文献库 / 最近添加 / 最近阅读 / 未分类 / 回收站」；自建分类可嵌套，新建、改名、
删除（只删分类不删条目）、拖动调整位置；底部标签选择器，可多选筛选，标签可着色。

**条目列表**：列为标题、作者、年份、期刊或会议、添加时间、阅读状态、附件图标；可排序，列的显示和宽度可调并保存；
快速搜索标题、作者、年份、标签、笔记文字；多选（Shift、Cmd/Ctrl）；拖到分类即加入，拖到标签即打标签；
右键：打开 PDF、在哪一栏打开、加入分类、移出当前分类、移到回收站、复制标题或 DOI；
键盘：上下选择、回车打开 PDF、Delete 移到回收站、Cmd/Ctrl+F 搜索。

**详情列**

- 信息：字段随条目类型变化，类型与字段取自 [`zotero-schema`](https://github.com/zotero/zotero-schema)
  （期刊文章、会议论文、预印本、书、书的章节、学位论文、报告、网页等）。字段可直接编辑并自动保存；作者可增删、排序。
- 笔记：每个条目可有多条富文本笔记（标题、列表、粗斜体、链接、引用块）。
- 附件：PDF 列表，可打开、改名、删除、在文件夹中显示（本地缓存位置）。
- 阅读状态：未读 / 在读 / 读完；用阅读器打开过自动变为「在读」。

**添加**：「+ 新建 ▾」选条目类型建空条目；拖入或选择 PDF，用文件名或 PDF 元数据里的标题建条目并附上该 PDF。

**回收站**：恢复、彻底删除、清空；默认 30 天后自动清空（可设置）。

## 5. PDF 阅读器

**打开**：条目上回车或双击，在栏里新开标签页 `gleeok://reader/?attachment=<key>`，
默认在第 3 栏（设置可改）；右键可选别的栏。标签标题用短标题，如「Vaswani 2017」。标签页随项目保存，
也参与跨设备接着用。

**阅读**（Zotero 阅读器自带）：翻页、跳页、缩放、适合宽度 / 整页、滚动和双页模式；侧栏有缩略图、批注列表、
目录；文档内搜索；复制文字；深色主题；阅读位置跨设备恢复（`onChangeViewState` → 服务器 → 下次的 `primaryViewState`）。

**批注**（Zotero 阅读器自带）：高亮、下划线、便签、文字框、区域截图、画笔；颜色、评论、标签；
批注列表筛选与跳转。`onSaveAnnotations` / `onDeleteAnnotations` 写回服务器，格式即 Zotero 批注格式
（`id, type, color, sortIndex, pageLabel, position, text, comment, tags, dateCreated, dateModified, authorName`）。

**嵌入方式**

- 阅读器运行在独立的原生网页视图里，像普通网页一样受栏、标签页、拆窗系统管理。
- 页面是打包进 Gleeok 的本地文件（阅读器构建 + 一层 Gleeok 外壳），通过专用的 preload 接口读 PDF、
  读写批注和阅读位置，不把文件系统或 Gleeok 的其他接口暴露给页面。
- 界面语言用 Zotero 的 zh-CN 翻译。
- `zotero/reader` 固定在某个 commit，用 `dev/build-reader.sh` 构建，产物放进仓库 `app/vendor/zotero-reader/`，
  附带 AGPL 许可证、上游 commit 号和构建脚本（满足 AGPL 提供源码的要求）。更新阅读器 = 改 commit 号重新构建。

## 6. 后端

**位置**：Gleeok 服务器里新增文献库模块，与项目、同步共用服务和令牌；本地模式下在 Gleeok 进程内运行。

**存储**

- 元数据：单独的 `library.db`（条目、分类、标签、笔记、批注、阅读位置）
- 文件：`<数据目录>/library/<附件key>/file`（服务器上默认 `~/.local/share/gleeok/library/`）
- 备份：扩展现有每日备份，带上 `library.db` 和文件目录（文件增量）

**数据格式**：条目用 Zotero 条目 JSON（8 位 key、`itemType`、字段、`creators`、`collections`、`tags`、
`deleted`、`version`、`dateAdded`、`dateModified`）；附件、笔记、批注是挂在条目下的子对象，各有 key 和版本；
阅读位置每个附件一条。

**接口**（仿 Zotero Web API，增量同步）

- `GET /api/library?since=<版本>`：返回该版本之后所有种类（items、collections、annotations、states）的改动和删除
- `POST` 新建；`PATCH` / `PUT` 带 `If-Unmodified-Since-Version`，版本不符返回 409
- `GET` / `PUT /api/library/items/<附件key>/file`：带 SHA-256 校验（`X-Content-SHA256`）
- 全库一个递增版本号，每次写入加一

**客户端缓存**：元数据本地缓存，离线可浏览、搜索；PDF 首次打开时下载到本地缓存，之后离线可读；
缓存默认上限 5 GB，按最近打开淘汰（可设置）。

**冲突**：条目按字段合并、后写入者胜；批注各自独立、后写入者胜；删除先进回收站。

## 7. 设置页「文献库」tab

PDF 默认在哪一栏打开；本地缓存上限与「清空缓存」；回收站自动清空天数；阅读器默认主题与缩放方式。
