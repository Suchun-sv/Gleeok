# Gleeok 日程 — Spec v1

任务 + 时间块 + 番茄钟，替代滴答清单。状态：M1–M5 已完成（2026-10-24）；M6（外部日历、导入、重复任务、提醒）以后再做。

## 1. 已定的决定

| | 决定 |
|---|---|
| 名字与位置 | 「日程」。跟文献库一样：侧边栏入口（日历图标，在「文献库」上面）、快捷键 Prefix+A（Agenda）、能占满右侧区域，也能作为 `gleeok://planner` 标签页放进任意一栏 |
| 项目 | 任务可以关联一个 Gleeok 项目，也可以不关联（「收件箱」）。项目设置抽屉里能看到该项目的任务 |
| 任务字段 | 标题、备注、截止日期（可带时间）、优先级（无/低/中/高）、子任务、预估番茄数 |
| 视图 | 日、3 日、周、月 |
| 时间块 | 与任务分开：一个任务可排多个时间块；时间块不会让任务完成；删除时间块不影响任务；也可以有不挂任务的时间块（「午饭」「组会」） |
| 完成 | 只有手动打勾才算完成；没做完的任务不会自动挪走 |
| 月视图 | 把任务拖到某一天 = 把截止日期设成那天 |
| 番茄钟 | 专注 25 / 短休息 5 / 每 4 个番茄长休息 15（可改）。专注结束后弹出确认，由用户决定是否开始休息；休息结束后同样确认是否开始下一个番茄 |
| 手机 | 做一个网页版（M5），由同步服务器提供，只在 tailnet 内可访问，可添加到 iPhone 主屏幕 |
| 已有日程 | Outlook / Google 日历以只读方式显示在时间轴上，放到 M6 |

## 2. 界面

```
┌ 日程 ───────────────────────────────────────┬ 任务 ─────────────────────┐
│ ‹ 今天 › 10月24日 周五   [日][3日][周][月]  │ + 添加任务，回车          │
│        周五 24       周六 25      周日 26    │ 今天 · 收件箱 · 全部 · 项目▾│
│ 09:00 ┌─────────┐                           │ ! ☐ 改 DS4D 讲义  今天 🍅1/3│
│       │改讲义 ▶ │   ┌─────────┐             │   ☐ 读 RAG 论文   周六 🍅0/2│
│ 10:00 └─────────┘   │读 RAG   │             │   ☐ 回导师邮件    DS4D      │
│ ━━ 10:37 ━━━━━━━    └─────────┘             │ ── 已完成 ──              │
└──────────────────────────────────────────────┴───────────────────────────┘
```

**日 / 3 日 / 周视图**：每天一列，纵向 0–24 点，打开时滚到现在附近；今天那列有一根「现在」横线，随时间移动。
把任务拖进时间轴生成时间块，默认长度 = 预估番茄数 × 25 分钟（至少 30 分钟），按 15 分钟对齐。时间块可上下拖、
跨天拖、拉下边缘改长短；点击弹出详情（所属任务、起止时间、开始番茄、删除）；空白处双击建不挂任务的时间块。

**月视图**：每天一格，列出当天的时间块和到期任务；把任务拖到某天 = 设截止日期；点日期跳到该天日视图。

**任务列表**（2026-10-24 改）：时间单选（今天（含已过期）/ 全部 / 已完成，另有回收站），项目多选标签
（收件箱和各项目，都不选就是全部）；列表按项目分组，每组标题右边有「+」，在那一组里新建（只看今天时截止日期默认今天）；
组可以折叠；把任务拖到别的组（标题或行上）就换了项目。每行显示勾选框、标题、截止日期、优先级颜色、番茄数（完成/预估）；
拖动排序；点开任务详情：备注、子任务、截止日期、
优先级、预估番茄数、所属项目、排过的时间块、番茄记录。

**在时间轴上新建**：在某天的空白处按住往下（或往上）拖，拉出一段时间（15 分钟一格），松手后输入标题：回车新建任务
（收件箱，截止那一天，番茄预估按时长）并占这段时间；「只占时间」（Shift+回车）只建时间块，比如午饭。单击不建，双击照旧建 30 分钟的块。

**在栏里**（宽度不到 860px）：任务列表在上、当天时间轴在下，中间的分隔条可以拖动高度或收起列表，任务直接拖进下面的时间里。
新标签页有「日程」：「今天」一排（今天的任务数、进行中或接下来的时间块、到期的任务，过期的在前，所有项目），
下面是当前项目的未完成任务（最多 6 个，过期、按日期、优先级）和一个直接添加到这个项目的输入框；点任务直接打开它的详情，
「在日程中查看全部」打开日程并只看这个项目。

**窄栏**：放进一栏时，时间轴和任务列表改为上下或切换显示。

## 3. 番茄钟

在任务行、时间块或任务详情上点 ▶ 开始。计时在主进程里，切换项目或关掉日程页都不中断；侧边栏「日程」那一行
常驻显示倒计时（如「🍅 18:32」），可暂停、跳过、停止。时间到弹系统通知并响铃，同时在窗口里弹出确认：
「开始休息 / 先不休息」；休息结束同样确认「开始下一个番茄 / 结束」。完成的番茄记到对应任务上；有每天的专注
时长统计。时长设置在「设置 → 日程」。

## 4. 后端

跟文献库同一套做法：服务器新增日程模块，单独的 `planner.db`，全库一个递增版本号，`GET /api/planner?since=N`
增量同步，`POST` / `PATCH`（`If-Unmodified-Since-Version`，冲突 409）/ `DELETE`，有自动化测试；本地模式在进程内
运行；每日备份带上 `planner.db`。

| 种类 | 字段 |
|---|---|
| tasks | key、title、notes、due（`YYYY-MM-DD` 或 `YYYY-MM-DDTHH:mm`）、priority（0–3）、subtasks（id、title、done）、estimate（番茄数）、projectId、done、doneAt、order（排序用）、deleted（回收站）、dateAdded、dateModified |
| blocks | key、taskKey（可空）、title（不挂任务时用）、start、end（带时区的 ISO 时间） |
| pomodoros | key、taskKey、taskTitle（任务删掉后仍能显示）、blockKey、kind（focus / short / long）、start、end、completed |

彻底删除任务时，它的时间块一起删除，番茄记录保留（靠 taskTitle 显示）。

## 手机网页版（M5）

服务器在 `/m/` 提供一个不依赖构建的小页面（`server/public/m/`）：今天的时间块和任务、收件箱 / 全部 /
已完成、快速添加、勾选完成、任务详情（标题、截止、优先级、子任务、备注、回收站）。它用同一个
`/api/planner` 同步，每 30 秒和回到前台时刷新。

部署：`server.env` 里设 `GLEEOK_MOBILE_URL`（例如 `tailscale serve --bg --https=8443 http://<tailnet-ip>:7420`
之后的 `https://<host>.<tailnet>.ts.net:8443/m/`）。桌面端 设置 → 日程 → 「复制手机登录链接」 得到
`…/m/#token=…`：在手机上打开一次，令牌存进 localStorage 并从地址栏去掉，然后「添加到主屏幕」。
这个链接就是服务器令牌，不要发到别处。
